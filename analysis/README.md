# Analysis guide

The initial project description names the methods below across six case studies. The individual case descriptions and the mapping between cases and methods are unavailable in this repository.

## Methods

| Method | Purpose |
| --- | --- |
| Analysis of variance (ANOVA) | Assess differences among group means. |
| Regression | Estimate relationships between an outcome and one or more predictors. |
| Paired equivalence testing | Assess whether the mean paired difference lies within specified equivalence bounds. |
| Control charts | Monitor process measurements or counts over time for signals of unusual variation. |
| Pareto analysis | Rank categories by their contribution to a total. |

## Software and outputs

The project used **Minitab**. The software version, settings, and analysis commands are undocumented in the repository. Datasets, saved Minitab projects, numerical results, and chart exports are also unavailable. Reproducing the analyses requires the source data and analysis settings.
