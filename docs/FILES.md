## Reviewing the work

Begin with the [English report](../reports/quality-control-report-en.md), then open the corresponding project in Minitab to inspect its saved session outputs and worksheet columns. The [output gallery](FIGURES.md) provides the chart images in report order. The [JSON data export](../data/worksheets.json) provides the stored cell values in a portable text format.

The native `.mpx` files are Minitab project files. They contain the saved state of the coursework and can be inspected with a compatible Minitab installation. Source worksheet names are retained to make navigation between the report, data export and native projects straightforward.
